Growing and Shrinking

Property flex adalah property yang kita sebut dengan shorthand di mana property ini adalah singkatan dari kombinasi beberapa property lain. Dalam kasus ini, flex berarti flex-grow, flex-shrink, dan flex-basis.

flex-grow

Flex-grow adalah property yang memerintahkan element untuk melebar (menjadi fleksibel) sesuai perbandingan. Misalkan ada 3 element yang menggunakan flex: 1; maka 3 element itu terbagi menjadi 3 bagian yang sama. Seperti contoh di bawah ini:

Flex: 1;
Flex: 1;
Flex: 1;

Dari contoh di atas, ketiga kotak div menggunakan flex:1. Namun semisal salah satu div mempunyai flex yang ukurannya lebih besar, maka flex yang valuenya lebih besar akan memakan tempat lebih banyak. sekitar n x total flex=1. Contoh:

Flex: 1;
Flex: 2;
Flex: 1;

Bandingkan dengan 4 box berukuran sama di bawah, anda akan dapat melihat bahwa flex:2 memakan 2 kotak yang ukurannya sama.

flex-shrink

flex-shrink adalah property dengan sifat lawan dari flex-grow. Apabila flex-grow berarti menentukan bagaimana suatu element 'tumbuh', flex-shrink menentukan bagaimana element menciut.

Jika zoom-out, div Shrink 2 akan mengikuti ukuran Shrink 1 dan 3 karena mereka semua punya flex-grow: 1 (yang di state di flex:1). Namun ketika kita zoom-in, maka flex-shrink akan terlihat ketika Shrink 2 tidak mengecil ketika mencapai ukuran width yang dinyatakan (250px). Di css disebutkan bahwa flex-basis nya dijadikan auto karena ketika flex-basis:0 maka ia tidak akan menghiraukan width nya. Sedangkan kalau auto dia kan mengikuti deklarasi width.
