CSS Tricks Flexbox

This is a page to practice Flexbox properties based on the guide on css-tricks.com. I will try to make it as interesting and as detailed as the web as possible. Enjoy!

  1. Parent Properties

    Here we have the properties of flexbox for the parent (container).

    1. display

      Display is what defines the flex container. With it, the container becomes flex. On the example below, the purple rectangle is the flex container, while the grey box is just a regular container with explicitly defined height and weight. If you try to resize the screen, the flex container will change width but not the grey box.

    2. flex-direction

    3. flex-wrap

      flex-wrap is the property we set to control the flow of the flex item(s) behave inside the container. It fits all flex items inside the container, making rows if the width is not enough for everything. Basically the same as text wrap in many text editor.
